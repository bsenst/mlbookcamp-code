
2. Run the reference training to generate history files (takes ~10-15 minutes on CPU):
```bash
python reference_train.py --data-dir data --output-dir runs/reference
```

## Running the Solution
```bash
cd cohorts/2026/homework/08-deep-learning
python homework_08_solution.py
```

## What the Script Does
1. Answers Q1 and Q2 directly from model architecture
2. Reads `history_baseline.json` and `history_augmented.json` generated by `reference_train.py`
3. Computes:
   - Q3: Median of `train_accuracy` from baseline (rounded to 2 decimals)
   - Q4: Population std of `train_loss` from baseline (rounded to 3 decimals)
   - Q5: Mean of `evaluation_loss` from augmented (rounded to 3 decimals)
   - Q6: Mean of last 5 `evaluation_accuracy` from augmented (rounded to 2 decimals)

## Expected Output
```
Q1. Loss function: nn.BCEWithLogitsLoss()
Q2. Total parameters: 20073473
Q3. Median baseline train accuracy: (computed from history)
Q4. Std baseline train loss: (computed from history)
Q5. Mean augmented eval loss: (computed from history)
Q6. Mean last 5 augmented eval acc: (computed from history)
```

## Reference Training Details
The `reference_train.py` script:
- Uses fixed seed (42) for reproducibility
- Trains for 10 epochs baseline + 10 epochs augmented
- Uses deterministic algorithms and CPU
- Saves history JSON files for grading
